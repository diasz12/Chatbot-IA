# Chatbot usando Inteligência Artificial

## Descrição do Projeto
Projeto para criar uma solução eficiente para automatizar interações com clientes de uma empresa. O chatbot visa melhorar a experiência do usuário e otimizar processos de atendimento.

## Funcionalidades
- Respostas automáticas para perguntas frequentes.
- Capacidade de aprendizado para melhorar as interações com base em dados.
- Personalização do tom e estilo das respostas.

## Tecnologias Utilizadas
- Linguagem de programação: Python, Javascript, html e css
- Frameworks: Flask
- Biblioteca de Processamento de Linguagem Natural: API OpenAI
- Ferramentas de versionamento: GIT

## Resultados Esperados
- O chatbot será capaz de responder perguntas com precisão.
- Melhoria contínua nas interações com base em feedbacks.
